# FACTS — 另一个你

| 片中说法 | 来源 / 推算 |
|---|---|
| 宇宙里很可能还有一个你；最近的另一个你约在 10^(10^29) 米外 | Max Tegmark, *Parallel Universes*, arXiv:astro-ph/0302131 (2003), abstract: "...you have a twin ... about 10^10^29 meters from here." 前提：空间无限（或足够大）且物质分布大体均匀（遍历性）。同年 Scientific American 科普版写作 10^(10^28) 米；片中用原论文。 |
| 前提（宇宙无限）还没人知道 | Tegmark 同文把这一级平行宇宙列为依赖"空间无限 + 均匀"的推论；观测只能检验可观测宇宙内的平坦与均匀，无法证明无限。 |
| 3×3 黑白像素格最多 512 种图案；第 513 次必然重复 | 2^9 = 512；鸽巢原理。 |
| 1 后面跟 10^29 个零 | 10^(10^29) 的十进制写法有 10^29 个零。 |
| 每毫米写一个零，要写约 106 亿光年 | 10^29 mm = 10^26 m；1 光年 = 9.4607×10^15 m → 1.057×10^10 光年 ≈ 106 亿光年。 |
