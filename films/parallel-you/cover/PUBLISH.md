## 小红书

**标题**（三选一）
- 宇宙里，可能还有一个你🌙
- 另一个你，离你 10^10^29 米
- 用一道数学题，算出平行世界的你

**正文**
```
如果宇宙无限大，你可能不是唯一的你 🌌

🔲 先看一道小题：
3×3 的格子，只有黑白两色
最多只能拼出 512 种图案
第 513 次，一定和前面某次重复

⚛️ 把格子换成原子，道理一样
你身边这一团空间，粒子的排列多得吓人
但仍然是有限的

♾️ 如果宇宙无限大、物质又处处差不多
同样的排列，就一定会在某处再次出现
——包括你，和此刻正在看这条笔记的你

📏 物理学家泰格马克估算：
最近的另一个你，在 1 后面跟 10^29 个 0 米之外
每毫米写一个 0，光写这个数就要约 106 亿光年

❓但前提是，宇宙真的无限
这件事，还没人知道

如果真的见到他，你想问他什么？

📚 Max Tegmark, Parallel Universes, Scientific American (2003)

#平行世界 #平行宇宙 #宇宙 #物理 #冷知识 #科普 #涨知识 #纸雕
```
