# 一锅饭的一生（黄粱一梦）— 处理方案 · 80 年代赛璐璐动画版

风格：80 年代赛璐璐动画（`styles/cel-anime-80s/STYLE.md`，不变量全部保留）。竖屏 1080×1920，30 fps 输出（人物 12 fps 一拍二，表演 8 fps），约 72 秒。
故事来源：唐 · 沈既济《枕中记》（公版）。旁白：豆包 TTS 2.0「解说小明」。片尾不署名，全部原创。
上一版皮影方案存于 `archive-puppet/`（用户认为皮影不够生动、不够抓人，改用本风格）。

## 1. 三个候选结构

1. **按原文顺序讲**：客店 → 授枕 → 梦中一生 → 醒来。成语人人知道，没有悬念。
2. **一生是一盘录像带（选定）**：梦里的一生像一盘正在播放的录像带：爽、虐、再爽，快剪推进；他老死的那一刻，带子放完，蓝屏、雪花——然后**倒带**，画面飞速倒退，回到客店：锅里的饭还没熟。开头 3 秒是"预告片"式闪回（宰相冠、牢狱、刀、白发），先给结局碎片。
3. **系统流 HUD**：屏幕弹"叮！获得崔家千金"。贴合热门套路，但会盖住人物表情，而本风格的长处正是表情。

选 2：赛璐璐最擅长"脸上的戏"与"速度语法"，录像带的倒带是本风格独有的转场，正好就是"醒来"。

## 2. 一句话与弧线

**一句话**：穷书生卢生在一锅小米饭煮熟之前，过完了逆袭、跌落、再逆袭、老死的一生——带子倒回来，饭还没熟。

**官袍的颜色就是他的地位**（唐制：三品以上服紫，五品以上服绯，六、七品服绿，八、九品服青）：白麻布衣 → 青 → 绿 → 绯 → 紫 → 倒带回白衣。这是全片的"主角强调色"。

- 钩子（0–4 s）：锅盖在跳，金色蒸汽逆光；四个一闪而过的画面（紫袍金冠 / 牢栏 / 刀光 / 白发），每个 6 帧。
- 不得意（4–15 s）：黄昏的邯郸道客店，卢生叹气（特写：垂眼、皱眉）；老道士微笑，递出青瓷枕（插入镜头：枕上高光滑过，两端的孔透出光）。
- 入梦（15–19 s）：镜头钻进枕孔，白闪。
- 逆袭（19–27 s）：红灯笼逆光下的婚礼（新娘的眼睛特写）；金榜——他的名字，瞳孔放大、高光闪烁；官袍颜色随鼓点一次次换：青 → 绿 → 绯（光带扫过定格的人物）。
- 跌落（27–31 s）：紫色夜景，对头在阴影里耳语；冲击帧；他变成广阔山水里一个小小的背影（贬谪）。
- 再爬回（31–35 s）：侧向跟拍，多层视差，一路奔回长安宫门。
- 绝境（35–42 s）：静默一拍；牢里，眼睛大特写；拔刀——刀光星芒；冲击帧；崔氏的手抓住他的手腕（双手特写），泪。
- 巅峰（42–50 s）：一幅慢摇的"华丽定格"：紫袍、金冠、宫灯如海；儿孙满堂的群像；同一构图重画——他已白发，躺下。
- 带子放完（50–55 s）：老眼慢慢合上（三张画）；画面卡住 → 蓝屏 → 雪花，静。
- 倒带（55–60 s）：撕裂噪声、滚动条、"◀◀"；之前的画面飞速倒放（白发 → 紫袍 → 牢 → 金榜 → 婚礼 → 枕孔）。
- 醒来（60–66 s）：客店，卢生睁眼（三张画）；店家掀开锅盖：小米还是生的（插入镜头）；老道士笑。
- 回响（66–72 s）：他向老道士一拜，走进黎明的大路，定格；"换作是你，醒来以后，还会去赶考吗？"

## 3. 标杆

- 80 年代 OVA 的整体工艺（绘景与赛璐璐的反差、逆光、定格、速度语法）：学语法，不学任何作品的人物、镜头、标志。
- 短剧的节奏：每 2–3 秒一个情绪点，"爽"和"虐"交替；学节奏，不学任何剧情。

## 5. 配乐（city pop / 动画主题曲感 + 五声旋律）

FM 电钢、贝斯、门控军鼓、合成器铜管主奏一条五声音阶旋律（东方味 + 80 年代）。0–4 秒铜管一击 + 鼓过门；4–15 秒只留电钢与弦乐垫（客店的冷清）；19–35 秒全编制、越来越快（逆袭）；被贬处降成磁带/AM 质感（带通）；35 秒前**一拍真静默**；42–50 秒副歌、升半调（巅峰）；50 秒后音乐随画面卡住、变慢、停；倒带用磁带倒卷的尖啸；60 秒后电钢回到开场动机；结尾铜管一个不解决的和弦。

拟音：锅盖、蒸汽、灯笼、鞭炮（婚礼）、锣、脚步、马蹄、刀出鞘、冲击、泪滴、磁带"咔哒"、倒带尖啸、雪花噪声。

## 6. 字幕与标题

- 字幕在"带子上"：思源黑体 / Noto Sans SC 粗体，奶黄色、粗深色描边、柔和阴影，距底约 180 px（竖屏给平台按钮留位）。
- 片名《一锅饭的一生》：粗斜体中文 + 镀铬渐变（天蓝 → 白色地平线 → 紫 → 粉 → 金），霓虹描边，12 fps 闪现，星芒一闪。出现在第 1 镜末。
