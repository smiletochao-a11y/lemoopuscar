# 史实与出处

| 片中说法 | 依据 |
|---|---|
| 开元七年，邯郸道，老道士（吕翁），青瓷枕两端有孔 | 沈既济《枕中记》："开元七年，道者吕翁……邯郸道中"；"其枕青甆，而窍其两端" |
| 黄米饭 | 原文"主人方蒸黍"——黍即黄米；成语作"黄粱" |
| "我只想出将入相" | 原文卢生自述"建功树名，出将入相" |
| 娶名门崔家女儿，考中进士 | "娶清河崔氏女……举进士" |
| 一句谗言，被贬千里之外 | 为时宰所忌，以飞语中之，贬端州刺史 |
| 又一步步爬了回来 | 三年后征还，后同中书门下平章事（拜相） |
| 第二次下狱，拔刀自刎，妻子拦住 | "复诬与边将交结……下制狱……引刃自刎，其妻救之，获免" |
| 中书令，燕国公，儿孙满堂，活过八十 | 后为中书令，封燕国公；五子，孙十余人；"臣年逾八十" |
| 醒来，饭还没熟 | "主人蒸黍未熟" |
| 官袍颜色 青 → 绿 → 绯 → 紫 | 唐贞观四年服色制度：三品以上服紫，五品以上服绯，六、七品服绿，八、九品服青 |

演绎部分（只在画面）：喜轿与红灯笼、进士榜上的其他名字、牢狱与刀的样子、倒带等录像带效果、角色的造型。
