# 史实与出处

| 片中说法 | 依据 | 备注 |
|---|---|---|
| 755 年冬，玄宗在华清宫 | 《资治通鉴》卷二一七：天宝十四载"冬，十月，庚寅，上幸华清宫" | 庚寅 = 755-11-12（儒略历） |
| 安禄山起兵 | 同卷："十一月，甲子，禄山……反于范阳" | 甲子 = 755-12-16 |
| 消息送到华清宫 | 同卷："庚午，上闻禄山定反，乃召宰相谋之"；"丙子，上还宫" | 庚午 = 755-12-22；此时玄宗仍在华清宫（幸华清宫在前、还宫在后） |
| 第二年夏天，长安失守，一路向西 | 天宝十五载六月玄宗出逃长安，西行入蜀 | |
| 马嵬坡 | 天宝十五载六月丙申（756-07-15）马嵬驿之变 | 甲子 + 212 天 = 丙申（干支序 32），与公历一致 |
| "只剩两百多天"；印章 246 → 206 → 0 | 11-12 → 次年 7-15 = 246 天；12-22 → 7-15 = 206 天（756 年为闰年） | 画面数字为按日推算 |
| 她 38 岁 | 杨贵妃生于 719 年，卒于 756 年 | 虚岁 38（片中不念年龄，只作画面备注） |
| 白居易在她死后 16 年才出生 | 白居易生于 772 年；《长恨歌》作于元和元年（806） | 772 − 756 = 16 |
| "春寒赐浴华清池，温泉水滑洗凝脂" | 白居易《长恨歌》 | 文学作品，片中明确是"诗" |
| 海棠汤（片尾画面） | 1982 年发现唐华清宫御汤遗址，海棠汤平面呈海棠花形，俗称贵妃池 | 片中只作画面，不作断言 |
| 她每年冬天随玄宗去华清宫 | 玄宗多于每年十月幸华清宫、岁尽或开春还京，贵妃随行 | 旁白"照例"指玄宗的习惯 |

演绎部分（只在画面里，不在旁白里）：她试水、别花瓣、抬头的动作；骑者的样子；海棠花瓣与印章倒计时。
